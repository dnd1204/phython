### Belajar Script Python
- perintah yang paling dasar yaitu _String_
```python
print("hello there")
```
```hello there```
> Fungsi `print()`dalam bahasa pemrograman Python adalah command untuk menampilkan hasil didalam `()`
>  hanya dengan menggunakan tanda kurung dan kutip " akan menghasilkan

- contoh perintah nilai numerik (memasukkan angka tanpa tanda kutip)
```python
print(10)
print(3.2)
```
```
10
3.2
```
> jika hanya ingin menampilkan sebuah angka tidak perlu menambahkan kutip 1 ataupun 2

- Menggabungkan _String_ dan angka dengan operator koma `(,)`
```python
print('Hello', 10)
```
> Jika mengabungkan kedua bentuk String dan angka, gunakan tanda koma

- Menggunakan Fungsi * dan +
```python
print('Hello' * 3) # akan menduplicate string Hello sebanayk 3 kali
print(10 * 13 ) # akan melakukan perkalia bilangan tersebut

print('Hello' + 'guys') # akan menghubungkan  kedua string
print(10+3) # akan menambahkan kedua bilangan 
```
```
HalloHelloHello
130
Hello Word
13
```
> Jangan menggunakan + pada tipe data _String_ dan _integer_
contoh ```print ('hello'+ 5) # akan muncul error```

> tanda `#` adalah tanda yg sering dibuat sebagai komentar atau catatn pada penggunaan syntax.

## Tipe data dalam bahasa Pemograman Python:
|**Tipe Data**|**Contoh**|**Penjelasan**|
|---|---|---|
|Boolean| `True` atau `False`|Menyatakan benar `True` yang bernilai 1, atau false dan bernilai 0|
|String|`"Ayo belajar Python"`| Menyatakan karakter/kalimat bisa berupa huruf anka, dll `(diapit dengan tanda " atau ')`|
|Integer|`25` atau `1209`|Menyatakan bilangan bulat |
|Float|`3.14` atau `0.99`|menyatakan bilangan yang mempunyai koma|
|Hexadecimal|`0x9a` atau `0x1d3`|menyatakan bilangan dalam format heksa `(bilangan berbasis 16)`|
|Complex|`1+5J`|Menyatakan pasangan angka real dan imajiner|
|List|`['xyz', 768, 2.23]`|Data untaian yang menyimpan berbagai tipe data dan isinya bisa diubah-ubah|
|Tuple|`('xyz',789,2.23)`|Data untaian yang menyimpan berbagai tipe data tapi isinya tidak bisa diubah|
|Set|`{'apel','jeruk'}`|Kumpulan data unik yang tidak berutan dan tidak bisa memiliki duplikat|
|Dictionary|`{'nama': 'adi', 'adi':2}`|Data untaian yang menyimpan berbagai tipe data berupa pasangan penunjuk dan nilai|
